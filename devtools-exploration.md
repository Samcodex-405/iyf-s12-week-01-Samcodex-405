## Website 1: Example Domain

**Link:** https://example.com

### 1. What HTML tags are used on the page?

Some of the tags I found are:

-   `<html>` -- the main HTML element.
-   `<head>` -- contains page information.
-   `<title>` -- sets the page title.
-   `<body>` -- contains the page content.
-   `<h1>` -- displays the main heading.
-   `<p>` -- displays a paragraph.
-   `<a>` -- creates a link.

### 2. What is the page title?

The page title is **Example Domain**.

### 3. How many headings are there?

There is **1 heading**, which is the `<h1>` heading.

## Website 2: MDN Web Docs

**Link:** https://developer.mozilla.org/

### 1. What tag is used for the navigation menu?

The navigation menu is inside a `<nav>` element.

### 2. How is the search bar structured?

The search area is inside a `<div>` with the class `navigation__search`.

I found two versions: one for mobile screens and one for desktop
screens.

### 3. What happens when you hover over links?

When you move the mouse over a link, its appearance may change. For
example, its colour or underline may change.

In DevTools, I can check this by selecting a link, clicking `:hov` in
the Styles panel, and selecting `:hover`.

### 1. Identify 5 different HTML elements

I found these elements:

1.  `<div>` -- groups content together.
2.  `<h2>` -- displays a heading.
3.  `<p>` -- displays text.
4.  `<form>` -- contains the quiz choices.
5.  `<button>` -- creates the Submit Answer button.

### 2. Find a form element and list its inputs

I found a `<form>` containing a question:

**What is a correct syntax for assigning a value to a variable?**

It has four radio-button choices:

-   `x : 5`
-   `x = 5`
-   `x == 5`
-   `x -> 5`

There is also a **Submit Answer** button.
