## ♿ Accessibility Audit

Accessibility was an important part of this week's learning. I used Lighthouse and WAVE to evaluate my portfolio and identify areas for improvement.

**Lighthouse Accessibility Score:** 100/100

**WAVE Results:**

| Metric | Result |
|---|---:|
| Errors | 0 |
| Contrast Errors | 0 |
| Alerts | 0 |
| Features | 3 |
| Structure Elements | 9 |
| ARIA Elements | 5 |
| AIM Score | 10/10 |

### Improvements Made

- Added descriptive alternative text to images.
- Improved heading hierarchy using appropriate heading levels.
- Used descriptive link text.
- Added the `lang="en"` attribute to the HTML document.
- Used semantic HTML elements to improve page structure.
- Ensured form inputs have associated labels.

*Note: Automated accessibility tools are helpful, but manual testing is also important.*
